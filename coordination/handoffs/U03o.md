## Source supplied

- `native_process_driver.py` implements one owned `multiprocessing` spawn
  process and private pipe per instance, with bounded ready/go/terminal JSON,
  identity checks, terminal plus successful-exit evidence, exact-handle
  cancellation and idempotent close. A fresh instance never adopts a PID.
- `native_process_worker.py` is the import-safe spawn target. It scrubs the
  child to explicit runtime environment keys and disables dotenv before
  calling the trusted factory. It waits a bounded time for one go command,
  closes its session in `finally`, and sends only fixed status/identity/digest.
- `native_owned_binding.py` is a standard-library-only picklable binding class
  so spawn unpickling does not load backend `app.config` before scrubbing. The
  backend `native_owned_session.py` exposes that class. It pins host authority,
  validates a fixed bounded prepared-input manifest and READY identity before
  native side effects, creates the real `NativeSimulationSession` with a trusted
  model factory, and computes a bounded output digest after close.
- Source tests cover spawn ready/go, repeated observe, identity mismatch,
  cancellation, crash uncertainty, child environment isolation, guarded
  PostgreSQL coordinator attach/terminal/recovery/competition, and an actual
  both-platform offline OASIS child with unchanged prepared bytes and retained
  start claim. Architecture details and exact manifest encoding are in
  `docs/architecture/owned-native-process.md`.
