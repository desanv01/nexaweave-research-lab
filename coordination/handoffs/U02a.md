## Behavior and assumptions

The boundary accepts legacy IDs containing ASCII letters, numbers,
underscores, hyphens and internal dots; 128 characters is the chosen maximum.
It rejects Windows reserved device names case-insensitively. Configured roots
are trusted as resolved locations. Existing descendants, including final
files and same-root sibling links, are checked before access. Each occurrence
of an ID in route, body, and query is validated independently. Invalid listed
entries are skipped. A missing
simulation lookup no longer creates a directory. Fixed suffixes preserve flat
report JSON/MD support. Section indices are limited to integers 1–999;
the inherited generator uses `i + 1` when saving sections.
