## Intentional Markdown differences

Raw HTML and images display as text; neither creates active nodes.
Only explicit HTTP(S) links activate. Markdown headings are parsed
structurally, and only leading report-section level-two headings are
suppressed. Code fences cannot trigger heading suppression. Separate
ordered lists keep their actual Markdown starts rather than inheriting
a regex-generated sequence. Inputs over the cap show a fixed notice.
