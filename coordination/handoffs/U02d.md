## Behavior

The factory reads `MIROFISH_ALLOWED_ORIGINS` at startup unless a config class
explicitly overrides it. Defaults permit the two inherited Vite origins;
empty disables cross-origin access. Invalid entries fail before hooks and
simulation cleanup registration. Exact allowlist membership controls `/api/`
requests with Origin. Allowed preflights use route-supported methods and fixed
header names and never invoke business handlers. No-Origin clients and health
retain their existing flow. Request logs contain method, registered endpoint
identifier or `unmatched`, and status only.
Every `/api/` response carries `Vary: Origin`, including denied and no-Origin
responses. Config override precedence follows inherited explicit subclasses
before considering the environment. Invalid IP parse traces suppress the raw
parser exception context.

## Limits and Main review focus
