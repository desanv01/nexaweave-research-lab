## Required behavior

- simulation_dir is caller-provided trusted configuration, not a raw request ID;
  reject a link/reparse-point simulation_dir itself. Validate every IPC descendant
  with existing safe_path before open/stat/delete; do not pass ipc_commands as a
  newly trusted root that would mask a link there. Keep path attrs for compatibility.
- Validate command IDs as bounded portable resource IDs before appending .json.
  Preserve legacy IDs, not UUID-only. JSON filename stem must equal payload ID.
  Reject invalid/mismatched payload IDs before returning a command or writing or
  deleting a response. Response payload ID must equal client's awaited ID.
- Reject non-dict JSON, invalid enums, non-dict command args, malformed status
  objects without killing a poll loop. Corrupt candidates must not starve later
  valid files. Do not delete or quarantine rejected files automatically.
- Bound incoming JSON reads to 1 MiB bytes before decoding; reject oversized
  outbound messages before writing. This is a configurable module constant, not
  a claim of overall API body control. Unicode counts bytes. Catch expected
  validation/JSON/IO failures only, log without raw payloads or private paths.
- Write messages and env status via same-directory unique temporary files and
  os.replace, safe paths rechecked, cleanup only exact owned temp file; avoid
  exposing partially written messages. Do not blindly retry effects. Preserve
  independent command/response cleanup accepted in U01b.
- Use monotonic deadlines, retain timeout=0 immediate timeout behavior. Reject
  nonfinite/negative timeout and nonpositive/nonfinite poll interval before IO.
- Preserve command schemas, platform selectors, client/server public methods,
  interview behavior and error cleanup. No model calls, process launch, durable
  queue, auth or API changes. Document trusted-local-filesystem race limitations.
