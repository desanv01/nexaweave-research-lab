## Host and protocol

Keep current page request/reply contract unchanged. First read-only host is
explicitly bound to ONE configured display_graph_id and full canonical scope;
principal/config is trusted server input, not request JSON/headers claiming an
owner. This permits a runnable graph-view path without inventing an unsafe
public scope-discovery command. Document single-binding limitation openly.
Config supplies trusted interpreter/bootstrap paths, KNOWLEDGE_PRINCIPAL,
KNOWLEDGE_DISPLAY_GRAPH_ID, KNOWLEDGE_BOUND_SCOPE_JSON, database settings and
local bearer token. Validate all values at startup; no secrets in repr/logs/errors.
KnowledgeGraphReader validates binding; child checks the SAME principal/display
binding against ScopeBindingStore.resolve and exact requested canonical scope.
No automatic provision/migration; deployment operator explicitly preprovisions
accepted store binding. Document an explicit Python provisioning example.

read_bootstrap is a fixed trusted installed file executable through existing
KnowledgeProcessClient -I -u; import installed package, never sys.path hacks,
dynamic module from env, dotenv or caller-chosen script. Build dispatcher with
allow_model_calls=False, support page only in this host. Deny search/ingest/entity
(reader gets complete context through pages), never instantiate model clients.
Read-only provider uses existing page_graph/decorate semantics and a configured
Neo4j driver without Graphiti model initialization or index/schema mutation.
Injectable factory/driver for synthetic tests; normal mode never selects fake
models/data on failure. Close owned DB/Neo4j resources reliably; stdout is framing
only; stderr fixed messages only. Trusted Neo4j/Postgres endpoints are config,
not public data. Bound connection/query timeouts and no ambient PG overrides.
No LLM/embedding/reranker keys are needed or forwarded for read-only mode.

## Read/write coordination

Do not use a one-time authorize check followed by an unguarded provider call.
Add Ledger read context manager using a dedicated connection and per-scope
PostgreSQL session SHARED advisory try-lock. Derive a stable signed64 lock key
from group_id hash with domain separator; document collision means conservative
contention only. It must not collide conceptually with pair-key migration lock.
While shared lock held, short transaction verifies scope exists/canonical,
non-tombstoned and NO outstanding scope_admissions (running/uncertain writers
deny Busy). Commit that check BEFORE any Neo4j/network work, retaining only
session lock, not transaction/row lock. Finally release lock/close dedicated
connection on success/error/cancellation. No pool reuse with unreleased locks.

Ledger.claim and tombstone_scope acquire matching EXCLUSIVE advisory xact
try-lock BEFORE scope row locks; deny Busy while readers active. Scope write
admission still protects running/uncertain external writes after claim commits.
No TTL takeover, auto quarantine release or change to ingestion state semantics.
Existing writer can finish/tombstone only according to documented guards.
New reader cannot start while writer outstanding; new writer cannot claim until
read finishes. Existing code outside this disciplined ledger is not fenced.
Per-page consistency only; U03g live multipage limitations still apply. PG
connection loss can release lock while external read is ongoing; recheck liveness
before returning and discard on error, no distributed-snapshot/exact fencing claim.
Keep session lifetime bounded by host/transport deadline; no DB transaction spans
provider work. Use per-call connection factory; no blocking DB work on event loop.

Runtime wrapper holds read context across provider.page and releases after full
validated output. Fixed Busy/Tombstoned/Conflict/etc map existing dispatcher codes.
Host ownership policy remains mandatory; failure is deny, not empty graph.

## Flask read-only application

Explicit MIROFISH_APP_MODE=graphiti_readonly vs existing default legacy.
Config.validate read-only path validates its own settings, not LLM/Zep fields;
legacy validation unchanged. Startup read-only refuses DEBUG/nonloopback bind.
Do not launch server yourself. New factory registers only:
- /health with mode/capabilities only, no paths/secrets/DB details
- GET /api/graph/data/<graph_id> -> inherited success/data graph shape
- GET /api/graph/entities/<graph_id> -> filtered entity projection
- GET /api/graph/entity/<graph_id>/<entity_uuid> -> complete bounded context
Exact entity endpoint shapes documented. Other generation/mutation routes absent
or explicit unsupported, never inherited Zep handlers.
All API reads require configured nonempty high-entropy bearer token (>=32 chars,
bounded, printable; constant-time comparison). Missing/wrong token same401;
do not trust X-Forwarded-For or user-supplied principal/scope/DB settings. No token
in URLs, logs or child environment. Preserve explicit browser Origin policy;
allowlist parsing and fixed CORS preflight rules, not CORS as authentication.
Fixed public error codes/statuses; no exception strings/tracebacks. Unknown graph
binding404, Busy409/503 documented, validation400, unknown transport503. Never
swallow corruption into empty success. Facade lazily constructs bounded client
only from validated trusted host settings; no SDK imports in native backend.
