## Implementation

Replace script duplicate filesystem command polling/response/status writes with
delegation to accepted SimulationIPCServer. Keep each script handler's public
poll_command -> dict|None, send_response(command_id,status,result,error) and
update_status(status), environment/agent references, attrs and running flags.
Convert typed command to_dict at boundary, response status to CommandStatus.
Do not duplicate safe_paths/JSON/atomic logic or weaken shared validation.

Add a bounded public status method on the shared server, used internally by its
start/stop and by script adapters. Preserve timestamp/status and the parallel
handler's twitter_available/reddit_available booleans; only these optional flags
are allowed (no caller override of status/timestamp/path). Preserve inherited
alive/waiting/stopped etc lifecycle values actually emitted, with a bounded
string value rather than inventing a smaller incompatible enum. Paths/flags
must still traverse shared size/depth/path/regular-file protections.

Existing command handlers still own action/interview semantics; no model calls,
agent mocks presented as native agent results, no changes to selected platform
behavior or single/batch response structure. Malformed transport candidates do
not reach the script dispatcher. No new stdout payload/path/secret leakage.
