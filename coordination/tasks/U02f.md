## Purpose and scope

Do not yet wire Flask routes: upload admission/error mapping is the next slice.

## Contract

1. Parent API `extract_text_isolated(file_path, *, limits=None, timeout_seconds=30)`
   returns str. Reuse ParseLimits and safe ParseError categories. New safe errors
   may subclass ParseError in the new module: parser_timeout, parser_failed,
   parser_protocol_error. Validate a finite timeout 0<value<=120 (bool invalid),
   limits, path type and request bytes BEFORE spawning. Caller owns trusted-root
   admission. Resolve source to an absolute path; no command interpolation.
2. Launch only sys.executable with -I -u and the fixed sibling worker script,
   shell=False, close_fds=True, hidden window on Windows. No public command,
   interpreter, script or environment override. Child stdin/stdout are private
   pipes; stderr DEVNULL (never surface native diagnostics/document content).
   Unique TemporaryDirectory as cwd/home/temp, scoped cleanup via context manager.
   Minimal explicit OS environment allowlist, no copied keys/tokens/proxies,
   PYTHONPATH/startup hooks, provider variables or user settings. No dotenv load.
3. One strict UTF8 JSON request, at most16KiB, EOF terminated. Version1, absolute
   source path, exact ParseLimits fields. Child must reject duplicates, unknown
   keys, invalid version/types, oversized/deep invalid inputs with stable errors.
   Never import app/__init__, utils/__init__, Flask/config/LLM code: load only the
   fixed sibling file_parser module safely via importlib. Never evaluate input.
4. One strict UTF8 JSON response, EOF terminated: version1 plus either text or
   an allowlisted stable error code, not both. ensure_ascii=False. Parent bounds
   collected stdout before decoding/parsing: max_text_chars*6+4096 bytes (JSON
   escapes may expand sixfold); allow no extra output, duplicate/unknown fields,
   mismatched version, oversized text, invalid types or unknown errors. No source
   paths/document snippets/tracebacks in exception messages. Nonzero exits are
   parser_failed regardless of a success-looking response. Child catches parser
   errors and serializes only known codes; missing_file remains a safe category.
5. Bound parent work too: never use unbounded communicate() output capture.
   Concurrent bounded pipe I/O must avoid deadlock when child stalls, emits a
   large response, exits early or emits nothing. One monotonic deadline covers
   request transfer, response reading and process exit after spawn. On deadline,
   overflow, malformed response, I/O error or cancellation, terminate/kill and
   reap ONLY this owned child, close pipes and join owned I/O threads. No stray
   children/threads on normal/error paths. No broad process-name termination.
   The worker never launches descendants; document that native hostile code
   escaping a process is not contained. Popen startup itself and OS teardown are
   not claimed as a mathematically hard deadline. No automatic retries.
6. Keep output-only limits vs native transient memory limits explicit. Do not
   pretend environment scrubbing prevents native network/filesystem access.
   All safety conditions apply to TXT/MD as well as PDF encoding detection.
