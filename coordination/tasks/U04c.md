## User-visible purpose

Connect the retained source revision/citations from U04b to existing knowledge
scope bindings and operation coordinator. A trusted caller should select an owned
retained source and display graph, obtain a validated ingestion plan, and hand it
to the existing coordinator without resupplying or forging the document content,
hashes, source timestamps or evidence IDs. Keep facts distinct from assumptions.
An offline CLI exports this plan; it NEVER invokes a model or graph mutation.

ProjectStore owned record using scope.project_id. Require workspace/project match,
source layer, run_id/branch_id absent, no tombstone. Use SourceStore.get_source
under same principal/project; it revalidates stored hashes and passages. Require
at least one retained passage, keep all evidence IDs in original stored order.
Construct actual SourceEnvelope with entire exact retained text, original source

timestamps or inferred asserted_valid_at. Existing envelope max32768 codepoints
applies; refuse larger retained text explicitly, no truncation/silent chunking.

The returned immutable plan includes scope/source/ontology, existing canonical
request_fingerprint, and clear source provenance. Validate all arguments and any
returned DTOs, including Pydantic copy-bypass cases. No caller-provided content,
hash, evidence list, principal override, workspace or alternate scope accepted.
Map errors to fixed safe codes; no DB paths, credentials, source text in errors.
No schema initialization or ownership creation as a side effect of plan export.
