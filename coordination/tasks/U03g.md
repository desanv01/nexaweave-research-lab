## Scope

Build a stdlib-only backend reader over injected KnowledgeProcessClient-compatible
`client.call(request_bytes)->reply_bytes`. No Graphiti/Pydantic/Zep imports or
SDK construction; no environment/config reads, process launch, HTTP or DB calls
inside this module. This is the read-consumer bridge, NOT route/Flask cutover or
bootstrap. Trusted host binds scope and display graph ID; this does not authorize
that scope. Runtime dispatcher policy remains mandatory before future exposure.

## Construction and bounds

KnowledgeGraphReader(client, *, scope, graph_id, limits=None). Copy validated
scope once: exact full v1 scope fields, canonical UUID strings for required
workspace/project/graph and optional run/branch, known layer, integer1 notbool.
Require full fields as dispatcher serializes them. Scope is host-supplied data,
never derived from graph_id or replaced by a method argument. graph_id is a bound
legacy/display identifier, nonempty ASCII letters/digits/underscore/hyphen <=128.
Each method receiving graph_id must match the binding before client invocation.
Reject mutable caller changes affecting stored scope. No credential/endpoint keys.

Frozen ReadLimits: max_pages200 (cap2000), max_facts10000 (cap100000),
max_reply_bytes16MiB total (cap64MiB), timeout_seconds120 (cap300). Positive
integer counters, finite timeout notbool. Each top-level method gets one shared
budget across both node and edge scans and all context/enrichment work. Page
request limit100, bytes <=2MiB per reply, finite/depth32/duplicate-key-safe JSON.
Check monotonic deadline before/after each call and during projection loops.
This is a cooperative aggregate deadline, not preemption of arbitrary callables;
the concrete process client retains its own per-call deadline. No retry/cache.
On exceeded limits raise fixed reader error, never return a partial graph.

## Page protocol and validation

Only `page` method requests, fresh canonical request UUID, version1, copied bound
scope, payload kind node/edge with limit100/cursor and optional entity_type null.
Validate reply root/version/request ID/ok discriminator/exact result/error shape.
Only known dispatcher error codes may leave as stable KnowledgeReadError.code;
all malformed responses/exception text map fixed errors without raw data/repr.
Preserve KeyboardInterrupt/SystemExit; never map remote failures into empty data.
No fallback Zep, no provider search/ingest and no automatic remote retry.

Validate GraphPage schema1/facts<=100/next_cursor null or bounded nonempty string.
Validate current FactResult wire fields, exact bound scope and requested kind,
canonical provider/endpoint/episode/evidence IDs, nonempty episode provenance,
metadata labels/summary bounds and distinct nullable timestamps, plain attribute
object, finite optional score, correct basic field types. Metadata provided by
current U03f server must be retained, not inferred from arbitrary attributes.
Do not emit embeddings via a separate raw-record shortcut. Preserve evidence IDs
and temporal fields in explicit additional output fields; no silent data loss.

Across a kind scan enforce strictly increasing provider UUIDs, no duplicates,
no repeated cursor/cursor cycle; a continuation without progress is invalid.
Terminate only on next_cursor=None. Empty terminal graph is valid, but failed,
cycling, oversized, mismatched or incomplete scans must fail explicitly.
Pages are live, not a snapshot. Document race limitation; if combined graph has
an edge endpoint missing from its node set, fail fixed inconsistent_graph rather
than invent a node or present complete context. No cross-scope lookup permitted.

## Public read projections

Provide get_all_nodes(graph_id), get_all_edges(graph_id), get_graph_data(graph_id),
filter_defined_entities(graph_id, defined_entity_types=None, enrich_with_edges=True),
get_entity_with_context(graph_id, entity_uuid), get_entities_by_type(graph_id,
entity_type, enrich_with_edges=True). These use complete bounded page scans;
do not use the entity command's LIMIT100 neighborhood as complete context.

Mirror inherited EntityNode and FilteredEntities duck-typed dataclass fields and
to_dict/get_entity_type methods WITHOUT importing Zep. Entity shape uuid/name/
labels/summary/attributes/related_edges/related_nodes. Preserve first custom label
selection excluding Entity/Node, optional defined-type membership semantics,
incoming/outgoing relationship directions and stable deterministic neighbor order.
With enrichment off do not fetch edges. Context missing node returnsNone only
after a successful complete node scan; other errors must propagate safely.

Graph-data projection preserves graph_id,nodes,edges,node_count,edge_count;
node uuid/name/labels/summary/attributes/created_at; edge uuid/name/fact/fact_type,
source_node_uuid/target_node_uuid/source_node_name/target_node_name, attributes,
created_at/valid_at/invalid_at/expired_at/episodes. Use name for fact_type fallback.
Additional explicit evidence_ids and temporal/provenance fields are permitted
and should be documented. No coercion of arbitrary values into text; nullable
names/summaries map to empty display strings only at this legacy projection.
Avoid O(nodes*edges) enrichment: build adjacency and node maps once per operation.
