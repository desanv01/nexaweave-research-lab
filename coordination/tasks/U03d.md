## Architecture decision and scope

Use a versioned bounded command/reply boundary between Flask/native and the
isolated knowledge runtime. THIS SLICE is the in-process dispatch contract, not
the network/stdio transport. It opens no listener, initializes no providers and
reads no environment secrets. Future transport supplies an authenticated caller;
application ownership/lifecycle policy is injected, never inferred from group ID.
No new dependency, SQL/migration, provider behavior, frontend or Flask changes.

## Exact contract

`KnowledgeCommandDispatcher(provider, coordinator, authorize, *,
allow_model_calls=False, max_inflight=4, read_timeout_seconds=30)`.
All dependencies injected; authorize mandatory callable, allow flag strict bool,
max_inflight integer1..16, timeout finite0<seconds<=120, bool rejected.
`async dispatch(raw: bytes, *, principal: str) -> bytes`.
principal supplied out-of-band by trusted transport: nonempty, <=128 printable
ASCII chars; invalid is unauthorized. Principal is not part of client payload.

Request UTF8 JSON <=512KiB, maximum32 container nesting levels. Reject duplicate
keys at every level, NaN/Infinity, invalid UTF8, extra root keys, unknown method,
bad UUID/version/types before authorization/provider/coordinator calls. Version
must be exact integer1, never bool. Root exact fields:
`version`, `request_id` (canonical lowercase UUID string), `method`, `scope`,
`payload`. Scope is existing KnowledgeScope JSON representation, not group_id.
Methods and payloads:
- `page`: existing GraphPageRequest JSON object.
- `entity`: exact object {provider_id: canonical UUID string}.
- `search`: existing SearchQuery JSON object.
- `ingest`: exact object {source: SourceEnvelope JSON, ontology: OntologySpec JSON}.
Use Pydantic model_validate_json on strict reserialized nested objects so wire
UUID/datetime/tuple arrays deserialize correctly without permissive primitive
coercion. Preserve all existing DTO bounds, source hash and ontology checks.

After syntax/schema validation call `await authorize(principal, method, scope)`.
Only literal True grants access; False/None/exception denies. Must precede ANY
provider/coordinator work including response/status paths. Required policy can
include ownership/tombstones/read barriers; this library does not implement
those policies or turn its caller string into authentication. Never default allow.
No hidden retries. Return safe unauthorized without callback exception details.

Use a non-queuing active-call cap covering authorization and execution: if full,
return busy immediately; no unbounded waiting tasks inside dispatcher. Release
slot on every exit including cancellation. Single asyncio-loop instance; document
it is not thread/distributed admission. No global mutable principal/scope.

With allow_model_calls=False, search and ingest return model_calls_disabled with
no provider/coordinator work (authorization still applies). True is trusted host
configuration, not client input, NOT proof of budget/credentials authorization.
Production host must enforce configured monetary budget/provider policy before
enabling it. All tests synthetic; don't initialize real model clients here.

Routes: page->provider.page; entity->provider.entity; search->provider.search;
ingest ONLY coordinator.ingest, NEVER provider.ingest. Preserve coordinator's
durable admission/uncertain-write behavior; no generic transport-level timeout
that discards it, no manual release/reconciliation/retry. On caller cancellation,
propagate CancelledError through coordinator and release dispatcher slot; do not
convert cancellation into a success reply. Read/authorization awaits use bounded
cooperative timeout, including a post-await deadline check for suppressed cancel.
Document timeout limitations; do not pretend Python kills blocked native work.

Reply UTF8 JSON <=2MiB with exact fields version1, request_id (echo verified UUID
or null if invalid envelope), ok bool and exactly one of result/error. Errors
are fixed `{code: <allowlisted code>}` with no message/trace/input/path/credentials.
Map domain failures to fixed invalid_request, unauthorized, busy, not_found,
conflict, tombstoned, uncertain, unsupported, timeout, result_too_large,
model_calls_disabled, internal_error as appropriate. Unexpected provider or
validation exceptions must not leak details. For ingest an unknown exception
AFTER dispatch is uncertain, not a claim of no effect. Coordinator classes
define known pre-dispatch domain failures. No automatic mutation retry advice.

Success: revalidate result DTO (GraphPage/SearchResult) and EVERY fact's scope
equals request scope, canonical provider/endpoint/episode IDs, no NaN scores,
and finite serialized size; refuse rather than silently truncate/drop facts.
Limit SearchResult <=300 facts (existing combined3 kinds*100) and entity<=101;
page existing100. Do not invent rankings/temporal semantics or modify provider.
Ingest receipt must match group_id, expected episode UUID, full canonical
request_fingerprint and exact source evidence IDs; serialize only receipt fields
already exposed by CompletionReceipt.json_value. Never expose attempt IDs or
raw provider internals. On invalid ingest receipt return uncertain.

fingerprints. Valid Unicode/UUID/UTC scope roundtrips and each named method.
