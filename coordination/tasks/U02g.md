## Route contract

Keep POST /api/graph/ontology/generate. Before creating any project or saving any
file: validate required simulation_requirement (non-whitespace,<=20,000 chars),
project_name (default Unnamed Project, non-whitespace,<=200 chars), optional
additional_context<=20,000 chars; reject duplicate occurrences of these scalar
form fields. Preserve unrelated inherited locale handling. Do not log supplied
project name, requirement, additional context, filename or source text.

Require1..20 uploaded files. Reject an invalid member of a mixed batch rather
than silently dropping it: empty filename, unsupported extension, >255 filename
chars, control/NUL/CRLF, slash/backslash path components. Keep Unicode basenames
and current PDF/MD/MARKDOWN/TXT support. Reject no-extension/empty names safely.
No model constructor/call or project creation on admission failure. Stable
JSON success:false/error:<safe fixed string>/error_code:<fixed code>, HTTP400
for malformed admission,413 for numeric size/count/field-length limits.

Existing Flask MAX_CONTENT_LENGTH50MiB bounds total HTTP request. Explicitly
handle RequestEntityTooLarge from request.form/files before generic exception
handling; return safe413 without traceback or misleading500. No new Flask3.1-only
config assumptions. Multipart parser spooling happens before field validation;
document remaining request-rate/spooling and cross-process limits honestly.

## Bounded persistence

save_file_to_project preserves positional API/return fields; add keyword-only
max_bytes default50MiB, positive finite int (not bool), validate before IO.
Read source stream in bounded chunks and at most max_bytes+1 in total, never
file_storage.save unbounded. Do not trust filename/content-length MIME headers.
Use server UUID filenames and existing safe_path/ensure_directory checks;
exclusive creation avoids overwrite, no broad deletion. On limit/write failure,
remove ONLY the new partial file owned by this call and rethrow a safe classified
error. No orphan partial success; missing/IO errors never leak path or contents.
Caller route tracks sum actual file sizes <=50MiB and passes remaining capacity
to saver. No huge buffers. Trusted local-root/no-local-attacker race assumptions
remain; do not claim openat/OS sandbox immunity.

## Parse and aggregate contract

After admission, acquire a process-local nonblocking BoundedSemaphore(2) before
project creation. If unavailable return503 busy, no project/file/model effects.
Scope slots ONLY to save/extraction, release before ontology generation and on
every error/cancellation. Per-process—not global/distributed—limit documented.
Use accepted extract_text_isolated, not FileParser.extract_text in the route.
ParseLimits defaults50MiB/file,500 pages,5M chars/file,20 files,5M aggregate.
Total save/extract phase monotonic deadline90s; child timeout min(30s, remaining).
Do not start another save/parser if deadline expired; do not fabricate hard
deadline for OS IO/cleanup. Retain TextProcessor.preprocess_text behavior.
Combined document labels and separators count toward5M aggregate chars. Build
list/join once, no repeated unbounded concatenation; check BEFORE append/save/
generator. A blank/scanned document is not fabricated OCR; reject batch with
no usable text as422 no_extractable_text, no model call. All valid batch text
must be accounted for; no truncation/silent file omission.

After any parse failure do not call/construct OntologyGenerator or save combined
extracted text. Keep the newly created project as FAILED with safe error/code
and response data.project_id where available (preserves inspectable failure;
do not delete unrelated projects). Original successfully saved uploads may stay
on this failed project; document retention/deletion remains explicit user action.
ParseLimitError=>413; malformed/unsupported/invalid-source=>422;
ParserTimeoutError=>504; ParserFailedError/ParserProtocolError/missing source=>503.
No raw exception, source path, content, traceback in response or logs. Preserve
existing downstream LLMResponseError/provider-status behavior, including502 and
FAILED project; do not broaden this change to the rest of graph.py.
