## Shared renderer contract

Export renderSafeMarkdown(content, options={}) for browser callers and, if useful,
createSafeMarkdownRenderer(window) for isolated jsdom tests without global leaks.
Accept strings only; null/undefined/nonstring return empty string, no coercion or
object toString execution. MAX_MARKDOWN_CHARS=262144 code units; over limit return
a fixed escaped/plain visible notice (document it), do not parse or silently
truncate. No unbounded cache. Set markdown-it maxNesting=32, html=false,
breaks=true, linkify=false, typographer=false; no plugins or syntax highlighting.
Input bounds do not prove a hard browser CPU/memory deadline; state that limit.

Parse valid Markdown (headings, emphasis, inline/fenced code, paragraphs,
blockquotes, nested ordered/unordered lists, rules, tables). Code must display
literal HTML characters. Raw HTML is text, never executed. Images must not create
img or any network-loading nodes; render escaped alt text only. Links allow
explicit http:// or https:// only, no protocol-relative/relative/data/mailto/
javascript/file/vbscript. Invalid links stay inert text. No target=_blank needed.
No automatic remote requests, script, SVG, MathML, iframe, object, form, style,
event handlers, arbitrary id/name, custom elements, media or user-controlled CSS.

Use renderer/token rules to add fixed inherited classes BEFORE final sanitation:
code-block, inline-code, md-h2..md-h5 (headings shifted as inherited; deeper
headings valid h6), md-quote, md-li/md-oli, md-ul/md-ol, md-hr, md-p. Preserve
ordered list start numbers, nested-list indentation/data-level where existing
CSS expects it. Do not retain the regex trick that renumbers separate lists;
use actual Markdown starts and document this correction. Tables semantic only.
Keep optional stripLeadingSectionHeading=true for report sections, false by
default for user/agent chat. Do not strip headings inside code fences. Preserve
existing truncation/expand calculations before rendering; do not reinterpret
already-generated HTML as Markdown. Plain placeholder can be Vue text children.

DOMPurify final step with explicit minimal tag/attribute allowlists, no SVG or
MathML profiles, ALLOW_DATA_ATTR=false except explicitly generated data-level,
ALLOW_ARIA_ATTR=false. Limit attributes to fixed class, bounded numeric list
start/data-level, href/title where needed. No style/id/name/src/target. URL policy
must also be enforced in final sanitizer hook (not merely parser validation).
Sanitizer instance private, no globally mutable shared hooks. When DOM/sanitizer
unsupported fail closed to empty or fixed plain notice, never unsanitized HTML.
Never concatenate untrusted content or run replacements after sanitization.
All caller v-html and innerHTML values must come straight from safe renderer.

Official guidance Main reviewed: markdown-it/docs/safety.md recommends disabling
raw HTML; DOMPurify README warns post-sanitization modification can void safety.
https://github.com/markdown-it/markdown-it/blob/master/docs/safety.md
https://github.com/cure53/DOMPurify
