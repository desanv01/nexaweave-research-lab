## Required implementation

1. Validate untrusted resource IDs as bounded ASCII single components. Preserve
   existing generated IDs and fixtures using hyphens/underscores; do not impose
   a new UUID-only format. Reject empty/non-string/overlong IDs, dot segments,
   both separators, absolute/drive/UNC forms, colons, controls, trailing dots or
   spaces and Windows device names case-insensitively.
2. Validate final resolved targets strictly inside the trusted configured root,
   including existing descendants. Reject symlinks/junctions/reparse-point
   escapes, including files such as project.json, not merely the ID directory.
   Never allow the root itself as a resource or delete target. Use pathlib/commonpath,
   not string-prefix containment. Explicitly document the remaining local
   concurrent-symlink-swap threat; do not claim universal race-proof sandboxing.
3. Route project metadata/text/upload/list/delete, simulation manager/runner
   state/log/config/database paths, and report metadata/sections/logs/downloads/
   deletion through this boundary. Preserve legacy flat report JSON/MD support
   using validated IDs and fixed suffixes. Bound section indices and other
   filename selectors. Inspect direct API joins so routes cannot bypass helpers.
4. Validate before filesystem side effects, cache returns and subprocess launch.
   Read-only lookup must not create missing simulation directories. Mutating
   flows must explicitly ensure directories after validation. Invalid entries
   found during directory listing should be skipped safely rather than exposing
   outside files or breaking all listings.
5. Return a stable client-safe 400 error for invalid path inputs at affected
   API boundaries, without exposing a traceback or local path. Do not broadly
   swallow operational failures or rewrite unrelated report/simulation behavior.
6. Write adversarial tests (do not execute): traversal for Windows/POSIX,
   sibling-prefix escape, reserved names, invalid types, overlong IDs, nested
   symlink targets, outside sentinel read/write/delete preservation, legacy
   reports, valid existing IDs, missing reads without directory creation, and
   route status/payload. Gate OS-specific symlink setup explicitly if necessary;
   Linux CI must exercise symlinks. Use temporary fixtures only.
7. Handoff lists modified paths and behavior, remaining threats and uncovered
   call sites, implementation assumptions and suggested verification commands.
   No claim that U02 is accepted or the app is safe for public deployment.
