## Contract

SourceStore(connection_factory).ingest_text(principal,project_id,source_revision,
name,text,passages=()) -> immutable source record and evidence records atomically.
Principal domain exactly existing; canonical UUID project/revision. Existing
project owner required; unknown/wrong principal same NotFound, no auto project.
Name nonempty UTF8<=256 characters. text must be nonempty str UTF8<=1MiB, no NUL
or invalid Unicode; exact bytes/hash preserve BOM/newlines, no silent normalization.
Hash sha256(text.encode('utf8')), byte_length and codepoint_length calculated.
No file/provider/network access inside transaction. Immutable source identity:
same project/revision/name/content/passages retry idempotent; changed data conflict;
revision UUID belongs to one project. Server UTC recorded_at. No caller timestamps
claimed as source publication/validity. No updates/deletes in this slice.

Passages <=100, exact input fields evidence_id canonical UUID, start integer>=0,
end integer>start, page optional positive int or null. Offsets are Python Unicode
CODEPOINT half-open indices, not UTF8-byte/UTF16 offsets. end<=len(text), substring
nonempty, each excerpt UTF8<=32768 bytes, evidence_id unique. Derive excerpt and
excerpt_sha256 internally; caller cannot supply fake excerpt/hash. page metadata
is explicitly caller-declared, not verified extraction. Store scope/project,
source revision and evidence with relational constraints/composite FK and indexes.
Duplicate evidence ID across sources conflicts even if text equal. Validate/copy
and compute before transaction. Keep root source/passages insertion atomic on any
failure, no orphan partial source or evidence. Same revision concurrent identical
request idempotent; conflicting same revision only one winner.

get_source(principal,project_id,source_revision) -> retained content/metadata;
list_sources(principal,project_id,limit<=100) deterministic bounded metadata;
resolve_evidence(principal,project_id,evidence_id) -> exact excerpt, offset unit,
source metadata, hashes, page declaration and recorded timestamp. Revalidate
stored hash/text/offset relation on read; corruption raises fixed StorageError,
never empty/made-up citation. Return defensive copied/frozen records.

Keep distinction with U04a declared project evidence manifests: those remain
unverified references unless resolved in this store. Do NOT silently reinterpret
object_key as filesystem path or mark every old manifest verified. No automatic
