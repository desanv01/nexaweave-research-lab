## Contract

- Strict immutable v1 page request: kind=node|edge|episode, limit1..100 (default
  25), optional cursor<=1024 chars; optional entity_type only for node pages.
  Revalidate model_copy bypasses and scope before database access. Reject
  malformed types, unsupported filter/kind combinations and bad identifiers.
- Strict result: tuple of existing FactResult, optional next_cursor, schema1.
  Preserve complete KnowledgeScope and existing evidence decoration semantics.
- Keyset paging by canonical UUID string, ascending, exclusive cursor. Fetch
  limit+1 to determine next page; never silent OFFSET truncation or fixed100
  whole-graph claims. Build only fixed Cypher selected by validated kind. Bind
  group_id, cursor UUID, limit and optional entity_type as parameters. Entity
  type uses labels membership with a bound value, never dynamic query text.
- Node/episode queries constrain group_id. Edge query constrains relationship
  and BOTH endpoint groups. Also validate returned scopes/identities before
  returning results; never trust only query predicates or filter wrong-scope
  rows out silently. Provider UUID identifiers must be canonical valid UUIDs.
- Cursor contains version, exact group_id, kind, entity_type and last UUID.
  URL-safe base64 JSON with strict fields, bounded decoded size, duplicates
  rejected, no objects/eval/pickle or arbitrary query data. Validate cursor
  matches requested scope/kind/filter. It is navigation data, NOT authorization
  and need not claim a signature; changing it can only seek within the same
  authorized scope. Do not bind page size, so clients may change limit.
- Decorate facts using existing evidence validation. Incomplete/mismatched
  episodes must fail closed rather than become trusted graph facts. Keep
  temporal/evidence fields. Exclude embedding arrays and internal projection
  fields from attributes. Enforce a serialized result budget of1MiB, raising a
  stable bounded-result error instead of truncating facts/provenance silently.
- No extraction, embeddings, semantic/model search or mutation during paging.
  Each page is a live database view: concurrent mutations can affect later
  pages; explicitly do not claim snapshot consistency or historical versions.
- Documentation: current raw provider assumes already-authorized scope; future
  application service must gate tombstones/ownership/uncertain writes. This
  library page method is not permission to expose the raw provider publicly.

## Tests to write, not run

wrong scope/kind/filter, invalid limits/types/model_copy, fixed query parameters,
exact page boundary/next_cursor/end, changed limit, empty scope, wrong-scope
row, malformed provider UUID, incomplete evidence, oversized result, stripped
embeddings, no model/extraction calls. Use actual new enumeration implementation,
not copied helper logic. Cursor validation must precede driver access.

more than one page, verifies no duplicates/omissions in a stable graph and
node/edge/episode isolation. Verify edge endpoint isolation and incomplete
