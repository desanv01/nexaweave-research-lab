## Contract and mapping

Extend internal FactResult v1 additively with defaults:
- labels: tuple[str,...], default(), max64 entries, each nonempty <=128 characters;
  reject control characters and duplicates, do not silently truncate. Do not
  concatenate labels into Cypher or assume returned labels confer authority.
- summary: str|None defaultNone, <=32768 characters (Unicode preserved).
- expired_at: datetime|None defaultNone; when supplied require timezone awareness.

This is an additive internal wire extension before public release, not a changed
source/ontology fingerprint. Existing serialized fixtures without fields must
still parse. Validate through Pydantic, including model_copy bypass at existing
boundary revalidation. Keep existing scope, identifiers, provenance and limits.

Populate node labels/summary consistently in _fact (ingest/search), page row
mapping and entity detail. For page/entity prefer actual Neo4j labels(n), not an
arbitrary properties['labels'] shadow field. Entity detail query must return
labels(n) AS labels alongside properties(n); keep parameterized scope checks.
Missing summary mapsNone (empty summary stays empty); never invent it from fact.
For edges preserve expired_at independently of valid_at and invalid_at; do not
equate expiry/invalidation or reinterpret historical-query support. Convert
Neo4j temporal objects via existing _native before DTO validation.

Do not hide metadata in arbitrary attributes: exclude labels, summary,
expired_at from attributes when explicitly represented. Preserve other existing
attributes and embedding filtering. Do not change query pagination/order/scope,
search recipes, model configurations, budgets, ingestion identity or lifecycle.
Episode facts retain defaults for node-only fields. Output remains bounded by
existing page/command limits; invalid/oversize metadata fails, never truncates.
