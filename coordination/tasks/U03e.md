## Framing

Exactly one request and response per process, four-byte unsigned big-endian
length then UTF8 JSON payload. Request max512KiB, response max2MiB. Reject
zero/oversize length before allocation/read, partial header/body, trailing bytes,
invalid UTF8, non-object, duplicate keys, NaN/Infinity and excessive32-level
container nesting. Both sides read exact bounded lengths and then EOF; the
parent closes stdin after request. No newline delimited guessing, unbounded
communicate output, tempfile payloads or arbitrary command execution from JSON.

## Backend client

`KnowledgeProcessClient(python_executable, bootstrap_script, *,
timeout_seconds=120, child_environment=None)`; trusted host construction only.
Absolute existing executable/script paths. Bootstrap must be regular .py and
reject symlink/reparse leaf. A host-selected venv interpreter may be a symlink:
validate its resolved target is a regular executable file, but retain the original
absolute venv invocation path so its environment is preserved. Broken/looping
links/directories reject safely. Interpreter file path has no shell parsing.
No request-level command,
script, interpreter, environment or principal parameters. These host paths grant
execution of trusted code; they are NOT a sandbox. Never feed browser data here.
No arbitrary argv extension. Fixture bootstrap path is supplied at construction
just like a host-owned bootstrap would be, never inside a request.

`call(raw: bytes) -> bytes` returns strictly validated matching reply JSON.
Validate request bytes/root before spawn, exact fields version/request_id/method/
scope/payload, version int1 notbool, canonical request UUID, four known methods.
Nested scope/payload are objects; dispatcher remains authoritative DTO validator.
Do not infer whether a mutation is safe to retry from transport errors.

Spawn explicit [python_executable,-I,-u,bootstrap_script], shell=False,
close_fds=True, CREATE_NO_WINDOW on Windows. Unique TemporaryDirectory cwd/home/
temp. Start from minimal explicit OS variables like parser process helper, no
ambient provider keys/tokens/proxies/PYTHONPATH/startup/working-folder dotenv.
Optional child_environment is trusted host-supplied mapping: validate str keys/
values, total<=64KiB, keys uppercase ASCII starting KNOWLEDGE_ only, reject NUL
and duplicate/case-confused names. Never log/repr its values or expose them in
errors. Host may explicitly pass future credentials, but tests only sentinels.
Telemetry disabled explicitly. Environment scrubbing is not a network sandbox.

One nonblocking threading lock per client; concurrent call returns fixed busy
error immediately. Not distributed/cross-instance concurrency. Finite timeout
0<seconds<=300, bool/NaN/Infinity invalid. Concurrent bounded pipe writer/reader
avoids Windows deadlock; one monotonic deadline after spawn covers request send,
response, EOF and process exit. No automatic retry. Every success/failure/cancel
cleans ONLY the owned child/pipes/threads/temp and releases lock. Child never
spawns descendants; hostile native escape not covered. Popen/OS teardown not
mathematically hard deadlines; don't use broad process-name termination.

Reply requires exactly version1, matching request_id, ok strict bool, and result
OR error. Result object; error exact{code:allowed dispatcher code}. No success
accepted on nonzero exit. Client fixed exception types/codes for invalid_request,
busy and transport_failure; transport failure conveys outcome_unknown=True once
child spawned, including timeout/protocol/EOF/nonzero; no stdout/stderr/input/
paths/credentials in public text. Application must inspect durable operation
state after lost mutation replies; don't offer blind retry/claim cancellation.
Stderr DEVNULL; validate response length before buffering. KeyboardInterrupt/
SystemExit propagate after owned cleanup, rather than becoming success.

## Knowledge-side library

`async serve_once(dispatcher, *, principal, input_stream, output_stream)` accepts
binary file-like streams, reads one bounded frame, awaits dispatcher.dispatch
with the HOST principal, writes one response frame and flushes. No app/Flask
startup, environment secret loading, authorization default or provider creation.
Use explicit principal argument; never extract it from client payload.
Handle protocol failure with bounded safe error reply (version1/request_id null/
ok false/error invalid_request) when possible, no traceback. Parent deliberately
treats a mismatched/null request ID on an otherwise valid request as unknown
transport outcome. Return deterministic exit/status indication for host wrapper;
do not sys.exit or close streams owned by caller. If dispatcher raises/cancels,
never invent completion; propagate after no success response. Reads are blocking
on private pipes in this one-shot host; parent enforces time/termination. Document
this is not an asyncio multiplexed server and should own its own child process.
Any stdout logging outside the protocol is a protocol failure, never accepted.
