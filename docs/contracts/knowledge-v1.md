# Knowledge boundary v1 (U01a spike)

All public DTOs are Pydantic strict, frozen models with `schema_version=1`. `KnowledgeScope` contains workspace, project, graph, optional run and branch UUIDs, and one of source, assumption, inference, simulation, analysis layers. Its `group_id` is an application-computed SHA-256 of the full canonical scope, prefixed `mf1_`. Neither a client nor a model can submit a group ID through a DTO. The caller must still authorize the scope before invoking the provider.

`SourceEnvelope` has revision, ontology revision and operation UUIDs; SHA-256 of UTF-8 content; document/event kind; bounded name and content; an aware recorded timestamp; optional aware asserted-valid timestamp; and evidence UUIDs. Unknown asserted validity remains `null` in the normalized episode result. Graphiti 0.30.2 requires a reference timestamp, so the adapter passes `recorded_at` when asserted validity is unknown. Its extraction prompts can infer fact validity from that timestamp. This is a temporal accuracy limitation and requires U03 correction/evaluation before C07 acceptance. Publication dates are not automatically treated as validity.

`OntologySpec` validates names, attributes, duplicate types, and known source-target pairs. It builds Graphiti Pydantic model classes with `create_model`, without executing ontology text. An edge type is mapped only to declared pairs. Entity types and edge types share no implicit fallback pair. Reserved Graphiti fields cannot be attributes.

`SearchQuery` bounds text to 2,000 characters and `top_k` to 1–100. `valid_at` and `recorded_before` currently raise `UnsupportedCapability`, before search. Hybrid search uses Graphiti's combined BM25/vector RRF recipe, or an explicitly configured cross-encoder recipe. Results carry provider ID, supplied scope/layer, timestamps actually returned, episode IDs, evidence UUIDs available in completed ingest markers, and scores only when Graphiti supplies them. Scope and referenced episodes are checked again after Graphiti returns. Direct entity lookup uses fixed, parameterized, group-filtered Cypher and a bounded relationship query.

`ingest` derives episode UUID v5 from scope and operation UUID. The pinned Graphiti `add_episode(uuid=...)` reads an existing episode, so this adapter first saves the episode with that UUID. A separate marker holds a fingerprint of the complete canonical scope, source envelope and ontology, including metadata and evidence IDs. Graphiti's Neo4j episode save replaces all episode properties, so the marker is separate. An existing request with a different fingerprint conflicts. A matching completed marker permits `already_exists`; an incomplete or missing marker yields `ReconciliationRequired`. Precreation and Graphiti failures are classified as uncertain, without automatic replay. Result scope, referenced episode IDs and normalized facts are checked before the marker becomes complete. This is a spike-level guard, not a concurrency-safe operation ledger. Parallel submissions with the same operation ID, marker loss, Graphiti partial writes and cross-store commits require U03's minimal PostgreSQL operation ledger and reconciliation before operational cutover.

`initialize`, `ingest`, `search`, `entity`, `close` form the async adapter interface. The package has no HTTP service yet. Backend auth, ownership checks, source registry, lifecycle/deletion, pagination, bounded traversal, passage-level provenance, historical search, progress, exports, and production retries belong to later phases. Graph groups are data partitions, never authorization.
