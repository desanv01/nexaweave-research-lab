# Protected PDF source workbench

U13c source-authored implementation at the Main-assigned accepted49020c7 base. UNVERIFIED: Main owns compilation, regression execution, browser/runtime evidence and acceptance.

The existing private workbench client remains the sole transport and authorization owner. The source chooser accepts one .pdf alongside .txt/.md/.docx. Explicit Prepare reads no more than 2 MiB, checks the PDF marker in the first1024 bytes and trailing %%EOF after Python byte-whitespace stripping, encodes canonical base64, computes input SHA256 and generates a revision. No PDF parser, rendering, OCR, model or graph operation is invoked. Prepared data and its payload are frozen. Editing invalidates the review; discard/auth reset/unmount clears private selection. Retain consumes that review once, clearing file/draft buffers before submission. Lost, invalid, cancelled or unknown outcomes retain only an inspectable attempt identity and never automatically POST again.

PDF retains use their own strict extraction keyset; inherited text/DOCX receipt schemas are not widened. Verification requires page_text coverage,1..100 exact page strings, matching declaration order/counts and immutable name/revision/input digest. All binary/input/structure persistence, original-document verification, binary binding and OCR flags must be false; layout/semantic quality remain unknown. Each page is at most32768 UTF8 bytes; text joined with exactly two newline characters is at most1MiB. Page declarations reconstruct codepoint offsets, empty-page state and SHA256. Python Unicode whitespace differs from JS trim: U+0085 is whitespace, U+FEFF is content. Forbidden C0/DEL characters and malformed surrogate text fail closed.

Nonempty page evidence IDs are reconstructed as UUIDv5 under the source revision namespace, using SHA1 and the UTF8 name pdf-page-text-v1: followed by the canonical compact JSON declaration with sorted keys empty,end,excerpt_sha256,page,start. Every returned passage must match its reconstructed ID, page, offsets and hash. Joined text metadata/digest and every excerpt are then recomputed. No receipt acceptance is based on shape alone.

The receipt displays page/empty/nonempty counts and collapsed page declarations, without automatically expanding returned page strings. EN/ZH/MS copy distinguishes transient extraction from persisted text and original visual document verification. Explicit Inspect performs the inherited GET and text/passages verification before emitting inspected evidence into the existing graph workbench. Stored PDF passage page numbers are labeled in the inspector/excerpt. Existing1..32768codepoint and nonempty-passage ingestion eligibility is unchanged; larger retained PDF text remains inspectable but cannot be ingested. Retain itself makes no graph/model request.

Accessibility follows installed local UI/UX Pro Max read-only quick-reference guidance: native labelled file controls, form feedback association, polite atomic feedback, focus outlines/return,44px controls, safe wrapping, collapsed details, inherited mobile breakpoints and reduced-motion handling. No hosted12ui, new dependency or global design change.
